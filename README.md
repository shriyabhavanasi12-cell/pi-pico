# The Raspberry Pi Pico

An interactive educational website introducing the Raspberry Pi Pico microcontroller and its electronic components.

## Features
- Introduction to the Raspberry Pi Pico
- Explanations of input components: switches, buttons and potentiometers
- Explanations of output components: LEDs, RGB LEDs and buzzers
- Interactive flip cards with hover animations
- Custom colours, gradients and responsive layouts

languages used:HTML,CSS,

## How to Use
1. Open the website.
2. Explore the different input and output components.
3. Hover over the cards to reveal more information.
4. Follow the link to learn more or create your own project.
